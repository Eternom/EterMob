# EterMob

Variants de mobs pour EterCraft : chaque mob qui apparaît naturellement devient un variant de son type (capacités
codées en dur, conditions d'apparition, rareté), avec un ratio de puissance qui multiplie tout ce qu'il fait.
Réglages dans `config.yml` ; `/etermob list` et `/etermob spawn <variant> [ratio]` pour tester (etermob.admin).
